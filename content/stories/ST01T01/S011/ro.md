Leul Leo se odihnește pe iarbă. O pasăre mică stă lângă Leo. Numele ei este Pip.

Soarele de după-amiază este foarte cald. Pip este obosită și îi este cald. Nu există umbră pentru Pip.

Leo se așază lângă Pip. Leo face o umbră mare cu corpul său. Acum Pip este la umbră răcoroasă.

Pip bea apă și cântă un cântec. Leo îi zâmbește micii sale prietene. Prietenii buni se ajută între ei.
