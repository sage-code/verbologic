Pip este o mică broască verde. El trăiește într-un iaz albastru. Pip stă pe o piatră caldă.

Pip vede o mică furnică în apă. Furnica este pe un băț subțire. Furnica este udă și îi este frig.

Pip împinge o frunză mare spre băț. Pip ajută mica furnică. Furnica merge pe frunza sigură.

Frunza mare este caldă și uscată. Pip și furnica se odihnesc împreună. Pip zâmbește cu noul său prieten.
