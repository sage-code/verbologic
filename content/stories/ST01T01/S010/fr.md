Pip le lapin sautille dans le jardin. Il voit une grosse pomme dans un arbre.

Pip saute haut dans les airs. La pomme rouge est trop haute. Pip s'assoit sur l'herbe verte.

Max le hérisson entre dans le jardin. Max pousse une boîte en bois solide. Il aide son bon ami Pip.

Pip monte sur la boîte solide. Il prend la pomme rouge et sucrée. Les deux amis mangent ensemble joyeusement.
