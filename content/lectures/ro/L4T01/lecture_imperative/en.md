Imperative sentences give **commands, instructions, requests and warnings**. Romanian uses the imperative a lot in daily speech: people guide each other's actions at home, in class, in the city, at work and in emergencies.

## The shape of a command

A command starts with the **verb** — there is no subject, because the listener is the subject:

| Command | Meaning |
| --- | --- |
| *Spune bună ziua.* | Say good day. |
| *Spune te rog.* | Say please. |
| *Spune mulțumesc.* | Say thank you. |

::term{addresses="imperative_spune-salut,imperative_spune-buna-ziua,imperative_spune-te-rog,imperative_spune-multumesc,imperative_spune-la-revedere"}
::

::callout{type="tip"}
A bare command can sound abrupt. Add **te rog** (please, informal) or **vă rog** (please, formal) to turn it into a polite request: *Spune, te rog.*
::
